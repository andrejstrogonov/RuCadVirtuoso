# PlantUML-диаграммы

Канонический набор — `release/` (актуальные версии с номерами `29..34` и т.д.),
в `./` — синхронизированные копии (обновлять из release вручную).

## Рендер SVG

На машине без `plantuml` (java не установлен) SVGs **устарели**: источник
правды — `.puml`. После установки PlantUML выполнить:

```
plantuml -tsvg -o . <release/*.puml>
plantuml -check <release/*.puml>
```

и синхронизировать SVGs в корневой каталог `diagrams/`.
